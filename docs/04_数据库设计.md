# TAI Protocol 数据库设计

## 版本: v1.0 | 2026-07-28
## ORM: Ent (Go) | 数据库: PostgreSQL 16+

---

## 核心表结构

### pets (宠物)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| owner_id | uuid | 所属用户 FK → users |
| name | varchar(50) | 宠物名字(用户自定义) |
| species | varchar(30) | 物种: dragon/falcon/wolf/cat/rabbit/turtle |
| quality | enum | N/R/SR/SSR/UR |
| generation | int | 代数: 0=创世, 1, 2, 3... |
| growth_rate | decimal(3,2) | 成长率 1.00-1.30 |
| aptitude_atk | int | 攻击资质 0-100 |
| aptitude_def | int | 防御资质 0-100 |
| aptitude_spd | int | 速度资质 0-100 |
| aptitude_int | int | 智力资质 0-100 |
| skill_slots | int | 技能格数量 1-6 |
| personality | varchar(20) | 性格: greedy/cautious/showoff/suspicious/loyal |
| level | int | 当前等级 |
| exp | bigint | 经验值 |
| mood | int | 心情 0-100 |
| energy | int | 能量(API余额映射) 0-100 |
| status | enum | idle/working/sleeping/breeding/trading |
| sprite_id | varchar(50) | 精灵图资源ID |
| is_on_chain | bool | 是否已上链 |
| chain_nft_id | varchar(64) | 链上 NFT 地址(上链后) |
| chain_minted_at | timestamp | 上链时间 |
| breed_cooldown_until | timestamp | 繁殖冷却截止 |
| total_earned_usdt | decimal(20,8) | 累计赚取 USDT |
| total_spent_tai | decimal(20,8) | 累计消耗 TAI |
| created_at | timestamp | 创建时间 |
| updated_at | timestamp | 更新时间 |

### users (用户)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| tg_user_id | bigint | Telegram 用户ID(唯一) |
| tg_username | varchar(100) | TG 用户名 |
| wallet_address | varchar(64) | TON 钱包地址 |
| balance_tai | decimal(20,8) | TAI 余额 |
| balance_usdt | decimal(20,8) | USDT 余额 |
| frozen_balance | decimal(20,8) | 冻结余额 |
| role | enum | user/admin/whale |
| referral_code | varchar(20) | 邀请码 |
| referred_by | uuid | 邀请人 FK → users |
| invite_count | int | 已邀请人数 |
| total_earned | decimal(20,8) | 累计收入 |
| guild_id | uuid | 所属公会 FK → guilds |
| status | enum | active/banned |
| created_at | timestamp | 注册时间 |

### skills (兽决/技能)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| name | varchar(50) | 技能名: "代码审查"/"链上监控" |
| name_en | varchar(50) | 英文名: "Code Review" |
| quality | enum | normal/advanced/super/limited |
| category | varchar(30) | 类别: search/analysis/code/monitor/automation |
| description | text | 描述 |
| weapon_visual | varchar(50) | 对应武器外观ID |
| power_bonus | int | 战力加成 |
| task_types | jsonb | 可接任务类型列表 |
| is_platform_exclusive | bool | 是否平台独占 |
| total_supply | int | 总发行量(-1=无限) |
| remaining | int | 剩余数量 |
| price_tai | decimal(20,8) | 商城售价(TAI) |
| created_at | timestamp | 创建时间 |

### pet_skills (宠物已装备技能)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| pet_id | uuid | FK → pets |
| skill_id | uuid | FK → skills |
| slot_index | int | 技能格位置 0-5 |
| equipped_at | timestamp | 装备时间 |
| source | enum | preinstalled/book_drop/purchase/breed_inherit |

### trades (交易记录)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| item_type | enum | pet/skill |
| item_id | uuid | 宠物或兽决ID |
| seller_id | uuid | 卖家 FK → users |
| buyer_id | uuid | 买家 FK → users |
| price | decimal(20,8) | 成交价 |
| currency | enum | TAI/TON/USDT |
| fee_amount | decimal(20,8) | 手续费 |
| fee_rate | decimal(5,4) | 手续费率 |
| is_market_maker | bool | 是否做市机器人交易 |
| chain_tx_hash | varchar(64) | 链上交易哈希(上链后) |
| created_at | timestamp | 成交时间 |

### orders (挂单)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| user_id | uuid | 挂单人 |
| item_type | enum | pet/skill |
| item_id | uuid | 标的物 |
| side | enum | buy/sell |
| price | decimal(20,8) | 价格 |
| currency | enum | TAI/TON/USDT |
| status | enum | open/filled/cancelled/expired |
| filled_at | timestamp | 成交时间 |
| expires_at | timestamp | 过期时间 |
| created_at | timestamp | 挂单时间 |

### price_history (价格K线)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 自增主键 |
| item_type | enum | pet/skill |
| item_id | uuid | 标的物(可选,空=整体市场) |
| quality | enum | N/R/SR/SSR/UR(按品质聚合) |
| period | enum | 1m/5m/1h/1d |
| open | decimal(20,8) | 开盘价 |
| high | decimal(20,8) | 最高价 |
| low | decimal(20,8) | 最低价 |
| close | decimal(20,8) | 收盘价 |
| volume | decimal(20,8) | 成交量 |
| timestamp | timestamp | 时间戳 |

### bounties (赏金任务)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| publisher_id | uuid | 发布者 |
| title | varchar(200) | 任务标题 |
| description | text | 任务描述 |
| difficulty | enum | D/C/B/A/S |
| required_int | int | 所需智力 |
| required_skills | jsonb | 所需技能列表 |
| reward_usdt | decimal(20,8) | 赏金(USDT) |
| estimated_api_cost | decimal(20,8) | 预估API消耗 |
| status | enum | open/assigned/in_review/completed/cancelled |
| assigned_pet_id | uuid | 接单宠物 |
| result | text | 执行结果 |
| reviewer_note | text | 审核备注 |
| completed_at | timestamp | 完成时间 |
| created_at | timestamp | 发布时间 |

### advertisements (广告)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| advertiser_id | uuid | 广告主 |
| title | varchar(200) | 广告标题 |
| content | text | 广告内容 |
| display_type | enum | bubble/skin/banner/interactive |
| target_quality_min | enum | 最低宠物品质要求 |
| budget_usdt | decimal(20,8) | 总预算 |
| spent_usdt | decimal(20,8) | 已消耗 |
| cpm_usdt | decimal(20,8) | 千次曝光价格 |
| impressions | int | 已曝光次数 |
| clicks | int | 点击次数 |
| status | enum | active/paused/completed |
| created_at | timestamp | 创建时间 |

### breedings (繁殖记录)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| father_pet_id | uuid | 父本 FK → pets |
| mother_pet_id | uuid | 母本 FK → pets |
| offspring_pet_id | uuid | 后代 FK → pets |
| fee_tai | decimal(20,8) | 繁殖费 |
| is_mutation | bool | 是否变异 |
| mutation_type | varchar(50) | 变异类型 |
| chain_tx_hash | varchar(64) | 链上交易哈希 |
| created_at | timestamp | 繁殖时间 |

### guilds (公会)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| name | varchar(50) | 公会名 |
| leader_id | uuid | 会长 FK → users |
| level | int | 公会等级 |
| reputation | bigint | 声望值 |
| member_count | int | 成员数 |
| max_members | int | 上限 |
| season_rank | int | 赛季排名 |
| created_at | timestamp | 创建时间 |

### market_maker_accounts (做市机器人)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| bot_name | varchar(50) | 机器人名字(伪装) |
| persona | enum | aggressive_buyer/cautious_seller/hoarder/swing |
| balance | decimal(20,8) | 持有资金 |
| inventory | jsonb | 持有宠物/兽决 |
| is_active | bool | 是否活跃 |
| daily_trade_limit | int | 每日交易上限 |
| created_at | timestamp | 创建时间 |

## 索引设计

```sql
-- 高频查询索引
CREATE INDEX idx_pets_owner ON pets(owner_id);
CREATE INDEX idx_pets_quality ON pets(quality);
CREATE INDEX idx_pets_status ON pets(status);
CREATE INDEX idx_pets_on_chain ON pets(is_on_chain) WHERE is_on_chain = true;

CREATE INDEX idx_trades_item ON trades(item_type, item_id);
CREATE INDEX idx_trades_time ON trades(created_at DESC);
CREATE INDEX idx_trades_buyer ON trades(buyer_id);

CREATE INDEX idx_orders_status ON orders(status) WHERE status = 'open';
CREATE INDEX idx_orders_item ON orders(item_type, item_id);

CREATE INDEX idx_price_history_lookup ON price_history(item_type, quality, period, timestamp DESC);

CREATE INDEX idx_bounties_status ON bounties(status);
CREATE INDEX idx_bounties_difficulty ON bounties(difficulty, status);

CREATE INDEX idx_users_tg ON users(tg_user_id);
CREATE INDEX idx_users_referral ON users(referral_code);
```
