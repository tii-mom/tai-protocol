## 第一部分：从 TON 成功项目中提取的爆点公式

### Notcoin（3500万用户，72小时500万）

爆点拆解：
- 零成本：打开就玩，不花一分钱，不需要钱包
- 一键操作：点屏幕就行，傻子都会
- 空投预期：所有积分"未来可能值钱"，这个"可能"就够了
- 社交裂变：邀请好友 = 双方加分，Squad 组队 = 集体排名
- Telegram 原生：不需要下载任何 App，聊天窗口里直接玩

**我们要抄的：零门槛 + 一键操作 + 空投预期 + 邀请裂变 + TG 原生**

### DOGS（24小时100万用户）

爆点拆解：
- "你有资格"：根据 Telegram 账号年龄自动计算空投额度，老用户天然有优势
- 零操作：不需要"玩"，只需要"领取"
- Durov 背书：狗的形象来自 Durov 的梗，天然有话题性
- 交易所抢上：Binance/OKX 同时宣布上线，FOMO 拉满

**我们要抄的：资格感（"你被选中了"）+ 零操作领取 + KOL/平台背书 + 交易所 FOMO**

### Hamster Kombat（3亿月活峰值）

爆点拆解：
- "你是 CEO"：给玩家一个身份/叙事（不只是点击，你在"经营交易所"）
- 每日密码：每天一个隐藏奖励，驱动日活回访
- 卡牌升级：简单的数值成长，"我比昨天强了"
- 交易所上市叙事："你的交易所要上市了"= 代币要涨了

**我们要抄的：身份叙事 + 每日回访钩子 + 数值成长感 + "要涨了"的持续暗示**

### Catizen（TON NFT 游戏标杆）

爆点拆解：
- 合猫：两只猫合成更高级的猫（简单、上瘾、有赌博感）
- 视觉可爱：猫 = 天然传播载体
- NFT 赋能：猫不只是游戏道具，是链上资产
- TON 基金会 Grant 背书

**我们要抄的：合成/繁殖的赌博感 + 可爱视觉 = 传播力 + 链上资产 = 价值感**

### 总结：TON 爆点公式

```
爆点 = 零门槛（不花钱/不下载/不学习）
     + 一键操作（点/领/合，不需要思考）
     + 即时反馈（数字在涨/宠物在动/余额在变）
     + 社交绑定（邀请/排名/组队/炫耀）
     + 稀缺 FOMO（限量/限时/错过没了）
     + 赚钱预期（"这东西以后值钱"）
```

## 第二部分：史玉柱操盘心法（逐条映射）

### 心法一：免费玩家是"内容"，付费玩家是"客户"

史玉柱原话逻辑：免费玩家存在的意义，是让付费玩家有优越感。

映射到 CodexPet：
- 免费用户：注册送一只"野生宠物"（最普通，1技能格，低资质）
- 付费用户：买限定宠物（6技能格，满资质，出厂自带超级兽决）
- 免费用户的宠物在排行榜上被付费用户碾压 → 社交压力 → "我也想要那只龙"
- 免费用户不是"不赚钱的用户"，是"帮付费用户制造优越感的道具"

### 心法二：6元首充——打破付费心理门槛

征途的"6元首充送神器"是中国游戏史上最成功的设计之一。

映射到 CodexPet：
- 首充 1 TON（约$1.3）→ 送一只"限定外观"宠物皮肤 + 一本高级兽决
- 不是"花钱买宠物"，是"花1块钱领一个超值礼包"
- 心理转换：从"我在投资一个不确定的东西"变成"我花1块钱买了个确定赚的东西"
- 一旦付了第一次，第二次就容易100倍

### 心法三：社交压力 > 个人欲望

征途里你不充值，你的帮派兄弟会被别人欺负。你不是为自己花钱，是"不能拖累兄弟"。

映射到 CodexPet：
- 公会赛季排名：你的宠物战力直接影响公会排名
- 如果你的宠物太弱，公会排名下降 → 公会成员会"建议你"充值升级
- 繁殖需要配对：你没有好的种宠 → 你得去借/买 → 社交压力驱动消费
- "你的好友 xxx 的宠物今天赚了 8 USDT" → 推送通知 → 攀比心理

### 心法四：全服公告——让所有人的消费都被看见

征途里有人充了10万，全服弹公告："恭喜 xxx 获得神器！"

映射到 CodexPet：
- "恭喜 xxx 繁殖出 SSR 变异暗影龙！"（全服弹窗）
- "xxx 的宠物在赏金任务中赚取了 50 USDT！"（社群推送）
- "限时拍卖：创世像素猫 #001 当前出价 25 TON！"（实时滚动）
- 每一次消费/收益都被放大展示 → 所有人都在看 → FOMO

### 心法五：限时 + 限量 + 绝版 = 不买就亏

征途的"限时充值返利"、"绝版坐骑"让无数人冲动消费。

映射到 CodexPet：
- 每周一款"限时宠物"，只卖 72 小时，过后永不复刻
- 赛季限定兽决：本赛季结束即绝版
- "创世 100 只"：编号 #001-#100，永远不会再有
- 倒计时器永远在屏幕上："距下一款限定宠物发售还有 02:13:47"

### 心法六：让穷人看到希望，让富人感到恐惧

征途里免费玩家偶尔也能爆到好装备（希望），付费玩家怕被超越（恐惧）。

映射到 CodexPet：
- 免费用户的宠物繁殖时有 5% 概率变异出 SSR → "不花钱也能出极品"（希望）
- 付费用户的限定宠物不是"永远最强" → 新限定可能更强（恐惧）
- 排行榜每周重置 → 上周第一这周可能被超越（恐惧）
- "你的宠物排名从第 3 掉到了第 17" → 推送 → 焦虑 → 消费

## 第三部分：数字藏品运营打法

### 中国数字藏品（鲸探/iBox）的核心套路

| 套路 | 具体操作 | 映射到 CodexPet |
|------|---------|----------------|
| 限量编号 | "敦煌飞天 #0234/10000" | "暗影龙 #037/200" |
| 盲盒 | 不知道开到什么 | 繁殖后代属性随机（开出来才知道） |
| 合成 | 5个普通合1个稀有 | 3只同系宠物合成1只高阶（消耗=通缩） |
| 赋能 | "持有者可参加线下活动" | "持有创世宠物者享受 3api.shop 5折算力" |
| 社交展示 | 设为头像/背景 | Telegram 个人资料展示宠物 |
| 二级市场 | 场外交易/群内交易 | 平台内交易 + GetGems 链上交易 |
| 抢购 | 定时开售，秒没 | 限量宠物定时发售，倒计时+抢购 |
| 空投 | 持有A空投B | 持有创世宠物空投限定兽决 |

### 数字藏品的致命教训

iBox 崩盘原因：只有炒，没有用。价格涨100倍后没有接盘侠，归零。

**我们的区别：3api.shop + 赏金任务 = 真实效用地板。** 宠物价格不会归零，因为它每天真的在赚钱。这是和所有数字藏品的根本区别。

## 第四部分：完整产品方案

### 4.1 用户旅程（傻瓜式，5步完成）

```
第1步：打开 Telegram → 搜索 @CodexPetBot → 点击 /start
第2步：3秒后，一只像素宠物出现在聊天窗口（自动注册，零操作）
第3步：宠物说"老板好！我是你的新宠物，帮我取个名字吧？"
第4步：取名 → 宠物开始"巡逻"（自动接最低级赏金任务）
第5步：第二天打开 TG，宠物说"老板，昨天赚了 0.3 USDT，在钱包里了"
```

没有注册表单。没有助记词。没有下载。没有学习成本。打开 TG 就有宠物。

### 4.2 宠物获取方式（三层）

| 方式 | 门槛 | 宠物品质 | 目的 |
|------|------|---------|------|
| 免费领取 | 零（打开Bot就有） | 最低（1格，低资质） | 拉新，让所有人进场 |
| 商城购买 | 1-50 TON | 中等（2-4格，中资质） | 付费转化 |
| 限时抢购/拍卖 | 50-500+ TON | 顶级（5-6格，满资质，预装超级兽决） | 鲸鱼消费 + FOMO 制造 |

### 4.3 宠物属性系统（梦幻西游简化版）

每只宠物：
- 品质：N / R / SR / SSR / UR（UR 仅创世+限定）
- 成长率：1.0-1.3（决定升级上限）
- 四维资质：攻/防/速/智（各0-100）
  - 攻 = 任务执行速度
  - 防 = 抗恶意任务/广告过滤
  - 速 = 响应延迟
  - 智 = 可接任务复杂度上限
- 技能格：1-6（越多越稀有，6格概率<2%）
- 性格：影响技能协同和广告偏好
- 代数：第0代（创世）> 第1代 > 第2代...（越高繁殖力越弱）

### 4.4 兽决系统（技能书）

| 品质 | 获取方式 | 效果 |
|------|---------|------|
| 普通 | 商城直购（$CPET） | 基础搜索、简单摘要、转发 |
| 高级 | 繁殖掉落(10%) / 赛季奖励 / 合成 | 竞品分析、代码审查、数据整理 |
| 超级 | 限时活动 / 极稀有变异(1%) / 拍卖 | 深度研报、自动化流程、链上监控 |
| 限定 | 赛季绝版 / 联名 / 创世专属 | 不可再获取，纯稀缺 |

打书机制（梦幻西游核心赌博）：
- 技能格满时打新书 → 随机覆盖一个已有技能（不可逆）
- 可能顶掉核心技能（心痛）→ 可能完美替换（狂喜）
- 这就是消耗引擎：玩家永远在打书，永远在消耗兽决

### 4.5 繁殖系统

- 两只宠物配对 → 7天冷却 → 产出1-3只后代
- 后代属性 = 父母加权随机 + 5%变异（可能出SSR）
- 代数衰减：第0代生2-3只，第1代1-2只，第2代概率性1只，第3代+退化
- 繁殖费：代币计价，代数越高指数增长
- 需要"找到配对对象" → 社交/市场/公会繁殖池

### 4.6 自动化层（Agentic Wallets）

宠物 7×24 自主运行：
- 自动匹配赏金任务（根据智力和技能）
- 调用 3api.shop 算力执行
- 自动交付 → 赚 USDT
- 自动用 $CPET 购买 API token（3api.shop）
- 自动将净收入转给用户
- 在用户设定限额内自主交易兽决/宠物

用户每天收到的消息：
```
🐉 暗影龙日报
今日收入：3.2 USDT（2个赏金任务 + 1条广告）
算力消耗：0.8 USDT（3api.shop）
净赚：2.4 USDT → 已转入你的钱包
当前排名：#127（↑23）
心情：😊 精力充沛
```

### 4.7 交易/收藏层（数字藏品逻辑）

- 限量编号（"暗影龙 #037/200"）
- K线图 + 涨幅榜 + 成交额（视觉冲击）
- 合成系统：3只同系 N 宠 → 合成1只 R 宠（消耗=通缩）
- 盲盒繁殖：后代品质随机（赌博感）
- 社交展示：TG 个人资料宠物卡片
- 赛季排行：战力榜/收入榜/升值榜

| 宠物首发 | 平台 mint → 直卖 | 100% 利润 |
| 兽决商城 | 直售 + 拍卖 | 100% 利润 |
| 提现费 | 余额→TON/USDT 收 3% | 被动收入 |

### 链上阶段（Phase 2+）

| 收入项 | 机制 | 预估占比 |
|--------|------|---------|

### 关键：平台不可替代性

用户不能绕过平台的原因：
1. 繁殖合约只有平台能部署（你不能自己"生"）
2. 兽决只有平台能 mint（你不能自己"造"）
3. 赏金任务池只有平台有（你不能自己"找活"）
4. 3api.shop 批量价只有通过平台合约才能享受（你不能自己"买便宜算力"）
5. 排行榜/公会/赛季只有平台能运营（你不能自己"排名"）
6. 限定宠物的稀缺性由平台控制（你不能自己"印"）

## 第九部分：风险红线

### 绝对不能做的事

1. 不能在任何官方渠道承诺"保证收益"/"稳赚不赔"
2. 不能让做市机器人和真实用户钱包有任何链上关联
3. 不能在链上阶段还保留"平台可以修改宠物属性"的能力
4. 不能让单一用户/机器人持有超过 5% 的宠物供给
5. 不能在没有真实效用的情况下开放超过 5000 人

### 必须做的事

1. 用户协议写清楚"数字收藏品，不承诺投资回报，价格可能归零"
2. 做市钱包和团队钱包严格隔离（不同设备、不同IP）
3. Phase 3（效用）必须在开放后 60 天内上线，否则叙事断裂
4. 每次"暴跌"后必须有"反弹"（不能让早期用户全部套牢）
5. 保留"紧急暂停交易"能力（防止黑天鹅踩踏）

## 第十部分：一句话总结

**前30天：让50个人觉得"这东西在涨"。**
**前60天：让2000个人觉得"我错过了暴富"。**
**前90天：让5000个人觉得"现在进场还来得及"。**
**前120天：让所有人发现"等等，这宠物真的在帮我赚钱？"**

从 FOMO 进场，从效用留下。
从投机开始，从生产力结束。
从链下做市，从链上透明。

这就是史玉柱会做的事。
