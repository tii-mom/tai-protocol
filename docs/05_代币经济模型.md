## 通缩机制

### 链级通缩 (TON 原生)
- TON 网络 50% 交易手续费自动销毁
- 项目越活跃 → 链上交易越多 → 销毁越多

### 平台级通缩
- 广告/赏金 USDT 收入的 10% → DEX 回购 $TAI → 永久 burn
- 打书失败 → 兽决 + 部分 TAI 销毁
- 繁殖费 → 30% 销毁, 70% 进金库

### 供给衰减
- 宠物繁殖代数衰减 → 新宠物产出自然减速
- 赛季末"天灾" → 淘汰底部 5% 宠物
- 兽决限量发行 → 高级兽决越来越稀缺

## 价值支撑公式

```
$TAI 内在价值 = f(
  3api.shop 算力单价 × 月消耗量,     ← 真实消耗锚
  月度广告/赏金 USDT 流入 × 回购比例, ← 外部现金流
  流通量                              ← 通缩后剩余
)
```

简化: 只要 3api.shop 有真实客户在付费买算力, $TAI 就有购买力地板。
