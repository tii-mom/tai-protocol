## Pet NFT (pet_nft.tolk)

### Storage Schema

```tolk
struct PetData {
    owner: address,
    name: slice,              // 宠物名字
    species: int,             // 0=dragon,1=falcon,2=wolf,3=cat,4=rabbit,5=turtle
    quality: int,             // 0=N,1=R,2=SR,3=SSR,4=UR
    generation: int,          // 代数 0=创世
    growthRate: int,          // 成长率 100-130 (÷100)
    aptAtk: int,              // 攻击资质 0-100
    aptDef: int,              // 防御资质 0-100
    aptSpd: int,              // 速度资质 0-100
    aptInt: int,              // 智力资质 0-100
    skillSlots: int,          // 技能格 1-6
    personality: int,         // 性格枚举
    level: int,
    exp: int,
    breedCooldownUntil: int,  // unix timestamp
    totalEarned: int,         // 累计收入 (nanoton)
}
```

### Messages

| Op | 名称 | 方向 | 参数 |
|----|------|------|------|
| 0x01 | mint | external → contract | PetData |
| 0x02 | transfer | owner → contract | new_owner: address |
| 0x03 | update_attrs | authorized → contract | level, exp, totalEarned |
| 0x04 | set_breed_cooldown | breeding_contract → contract | until: int |
| 0x05 | get_data | query → contract | - |

## Breeding (breeding.tolk)

### Messages

| Op | 名称 | 参数 |
|----|------|------|
| 0x10 | request_breed | father_nft: address, mother_nft: address |
| 0x11 | confirm_breed | request_id: int |
| 0x12 | cancel_breed | request_id: int |

### 基因算法 (伪代码)

```
offspring.growthRate = weightedRandom(father.growthRate, mother.growthRate) ± 5
offspring.apt[X] = weightedRandom(father.apt[X], mother.apt[X]) ± 10
offspring.skillSlots = max(father.slots, mother.slots) - random(0,1)
offspring.generation = max(father.gen, mother.gen) + 1

// 变异 (5% 概率)
if random(100) < 5:
    offspring.quality = min(parentQuality + 1, UR)
    offspring.apt[random_stat] = 100  // 某项满资质
```

### 繁殖费

```
fee = BASE_FEE * (2 ^ generation)
BASE_FEE = 10 TAI
// 第0代: 10 TAI, 第1代: 20, 第2代: 40, 第3代: 80...
// 30% 销毁, 70% 进平台金库
```

## TAI Token (tai_token.tolk)

### 标准: Jetton (TEP-74)

| 参数 | 值 |
|------|-----|
| total_supply | 1,000,000,000 * 10^9 (nanoton精度) |
| admin | 多签钱包 (3/5) |
| mintable | true (仅 admin, 用于生态激励释放) |
| burnable | true (任何人可 burn 自己的) |

### 特殊逻辑

```
// 回购销毁: 平台金库定期用 USDT 在 DEX 买 TAI → burn
fun burn_from_buyback(amount: int) {
    require(sender == treasury_address);
    total_supply -= amount;
    emit(BurnEvent(amount, "buyback"));
}
```

## Agentic Wallet (agentic_wallet.tolk)

### 基于 TON 官方 Agentic Wallets 标准

```tolk
struct WalletPolicy {
    owner: address,           // 用户主钱包
    agent: address,           // 宠物 Bot 地址
    dailyLimit: int,          // 每日支出上限
    allowedOps: int,          // 位掩码: 哪些操作允许
    isActive: bool,           // 是否激活
}

// allowedOps 位定义:
// bit 0: 接赏金任务
// bit 1: 展示广告
// bit 2: 购买算力 (3api)
// bit 3: 市场交易
// bit 4: 繁殖
// bit 5: 打书
```

### Messages

| Op | 名称 | 参数 |
|----|------|------|
| 0x30 | create_wallet | policy: WalletPolicy |
| 0x31 | update_policy | new_limit, new_ops |
| 0x32 | revoke | - (立即冻结) |
| 0x33 | execute | op_type, target, amount (Agent调用) |
| 0x34 | withdraw | to: owner, amount (用户提取) |
