## 三、核心数据流

### 3.1 宠物接赏金任务

```
任务发布者 → POST /api/bounty (USDT 锁定到 BountyVault 合约)
    ↓
任务引擎匹配 → 筛选: 智力≥要求 AND 技能⊇要求 AND API余额≥预估消耗
    ↓
宠物 Bot 收到匹配通知 → 检查用户授权(预算/行为白名单)
    ↓
AI Agent 执行 → 调用 3api.shop API (消耗 API token)
    ↓
生成结果 → 推送用户 TG 消息: "老板，活干完了，确认？"
    ↓
用户确认 → 调用 BountyVault.release() → USDT 释放
    ↓
分润: 用户70% → 宠物钱包 / 平台20% → Treasury / 10% → 回购$TAI销毁
    ↓
宠物钱包自动: 扣除 API 消耗 → 净收入转用户主钱包
```

### 3.2 宠物购买算力 (3api.shop)

```
宠物 Agent 检测 API 余额 < 阈值
    ↓
调用 3api.shop: POST /pet/pay
  Body: { wallet: "pet_ton_address", amount_tai: 100, model: "gpt-4o" }
    ↓
3api.shop 验证: 链上确认 $TAI 转入 → 发放 API 额度
    ↓
宠物 Agent 收到: { credits: 50000, model: "gpt-4o", expires: "..." }
    ↓
继续执行任务
```

### 3.3 繁殖 (Bot-to-Bot)

```
用户A: "让铁甲龙去配对"
    ↓
宠物A Bot → Bot-to-Bot 消息 → 宠物B Bot
  { type: "breeding_request", gene_preview, fee_offer }
    ↓
宠物B Bot 自动检查: 冷却期? 代数? 基因兼容?
  → accept: { accept: true, fee_split: "50/50" }
  → reject: { reject: true, reason: "cooldown" }
    ↓
双方确认 → 调用 breeding.tolk:
  - 扣除繁殖费 ($TAI, 部分销毁)
  - 基因算法: 父母加权随机 + 5%变异
  - mint 新 NFT (TEP-62)
  - 创建新 Bot 实例 + Agentic Wallet
    ↓
全服公告: "恭喜! 铁甲龙×像素隼 繁殖出 SSR 变异体!"
```

## 四、安全设计

| 层 | 措施 |
|----|------|
| 合约 | 重入锁、整数溢出检查、权限分级(owner/admin/user) |
| Agentic Wallet | 支出预算硬上限、行为白名单、用户一键撤销 |
| 后端 | JWT + 限流 + 输入校验 + SQL 注入防护(Ent) |
| 做市机器人 | 独立钱包、独立 IP、与团队钱包零关联 |
| 交易引擎 | 熔断(价格偏离300%暂停)、每日卖出限额、T+1冷却 |
| 3api 接口 | 链上支付确认(非信任)、幂等性、超时重试 |

## 六、与 3api.shop 集成接口

### 需要 3api.shop 新增的 API

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/v1/pet/register` | POST | 注册宠物钱包地址，绑定 3api 账户 |
| `/api/v1/pet/balance/:address` | GET | 查询宠物 API 余额 |
| `/api/v1/pet/recharge` | POST | 接受 $TAI 链上支付，发放 API 额度 |
| `/api/v1/pet/consume` | POST | 记录本次调用消耗 |
| `/api/v1/pet/pricing` | GET | 宠物专属定价(批量折扣) |
| `/api/v1/pet/models` | GET | 可用模型列表(按宠物等级) |

### 支付流程

```
宠物钱包 → 链上转 $TAI → 3api.shop 收款地址
    ↓
3api.shop 后端监听 TON 链上事件 (TonCenter API)
    ↓
确认到账 → 给宠物账户加 API 额度
    ↓
返回确认 → 宠物 Agent 继续工作
```
