### 2. Pet API 路由 (internal/handler/pet.go)

```go
// 新增路由组: /api/v1/pet/
func RegisterPetRoutes(r *gin.RouterGroup) {
    pet := r.Group("/pet")
    pet.POST("/register", handler.PetRegister)      // 注册宠物钱包
    pet.GET("/balance/:address", handler.PetBalance) // 查询余额
    pet.POST("/recharge", handler.PetRecharge)       // TAI 充值 → API 额度
    pet.POST("/consume", handler.PetConsume)         // 记录消耗
    pet.GET("/pricing", handler.PetPricing)          // 宠物专属定价
    pet.GET("/models", handler.PetModels)            // 可用模型(按等级)
}
```

### 3. 定价策略

| 宠物等级 | 折扣 | 可用模型 |
|---------|------|---------|
| N (普通) | 9折 | gpt-4o-mini, qwen-turbo |
| R (稀有) | 8折 | gpt-4o, claude-sonnet, qwen-max |
| SR (史诗) | 7折 | claude-opus, gemini-ultra |
| SSR/UR | 6折 | 全部模型 + 优先队列 |

### 4. 链上支付确认流程

```
宠物 Agentic Wallet → 发起 Jetton Transfer (TAI → 3api treasury)
    ↓
3api 后端 TON Indexer 监听事件 (TonCenter WebSocket)
    ↓
匹配: tx.destination == treasury AND jetton == TAI_ADDRESS
    ↓
等待确认 (1秒, Catchain 2.0 亚秒最终性)
    ↓
确认 → 计算 API 额度: credits = amount_tai * rate * discount
    ↓
写入 pet_api_credits 表 → 返回确认
    ↓
宠物 Agent 收到确认 → 继续执行任务
```

### 5. 新增数据库表 (3api 侧)

```sql
CREATE TABLE pet_accounts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    ton_wallet_address VARCHAR(64) UNIQUE NOT NULL,
    user_id UUID REFERENCES users(id),  -- 关联 3api 用户(可选)
    pet_level INT DEFAULT 0,
    api_credits DECIMAL(20,8) DEFAULT 0,
    total_consumed DECIMAL(20,8) DEFAULT 0,
    total_recharged_tai DECIMAL(20,8) DEFAULT 0,
    status VARCHAR(20) DEFAULT 'active',
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE pet_api_usage (
    id BIGSERIAL PRIMARY KEY,
    pet_wallet VARCHAR(64) NOT NULL,
    model VARCHAR(50) NOT NULL,
    input_tokens INT,
    output_tokens INT,
    cost_credits DECIMAL(20,8),
    task_id VARCHAR(64),  -- 关联 TAI Protocol 赏金任务
    created_at TIMESTAMP DEFAULT NOW()
);
```
